# 💰 FinKalk — сайт финансовых калькуляторов для Польши

Статический сайт на польском языке с бесплатными калькуляторами. Поляки находят их через Google,
а доход идёт от рекламы Google AdSense и партнёрских ссылок (банки, брокеры, кредиты).
Хостинг бесплатный (GitHub Pages).

## Что внутри
- `site/` — 9 калькуляторов: procent składany, kredyt (rata), nadpłata kredytu, lokata (с podatkiem Belki 19%), obligacje skarbowe (EDO/COI/TOS/ROR/DOR), IKZE (ulga podatkowa 2026), dochód pasywny (zasada 4%), wynagrodzenie brutto/netto, B2B
- `site/assets/site.js` → `SITE_CONFIG` — ID AdSense
- `site/assets/partners.js` → `PARTNERS` — партнёрские ссылки; блок с пометкой «Reklama» появляется под результатом, как только заполнен `url`
- `.github/workflows/pages.yml` — автопубликация на GitHub Pages

## Что нужно сделать вам (за вас это сделать нельзя — нужен ваш аккаунт и данные для выплат)
1. **Включить сайт:** GitHub → Settings → Pages → Source: **GitHub Actions**, затем Actions → «Deploy site to GitHub Pages» → Run workflow.
   Адрес: `https://kavasss.github.io/asist/`
2. **Google Search Console:** добавить сайт и отправить `sitemap.xml`.
3. **Партнёрские сети с финансовыми офферами в Польше** (регистрация бесплатная):
   - [MyLead](https://mylead.global) — польская CPA-сеть, много финансовых офферов
   - [Systempartnerski.pl](https://systempartnerski.pl) — банки, кредиты, конты
   - [Afilo](https://afilo.pl) — сеть, специализирующаяся на финансах
   - [Comperia](https://www.comperia.pl) — сравнение кредитов и вкладов
   - [Awin](https://www.awin.com/pl), [TradeTracker](https://tradetracker.com/pl/) — крупные международные сети

   Получите ссылки на офферы (lokaty, konta maklerskie / IKE, kredyty konsolidacyjne, karty kredytowe)
   и вставьте их в `site/assets/partners.js`.
4. **Google AdSense:** подать заявку, после одобрения вписать `ca-pub-…` и slot в `SITE_CONFIG`.
   Для ЕС AdSense требует баннер согласия на cookie (GDPR) — включите бесплатный CMP в
   AdSense → «Prywatność i wiadomości».
5. **Налоги:** доход из Польши/от польских сетей нужно декларировать. Многие сети платят
   физлицам или требуют JDG/działalność nierejestrowana — уточните у сети и бухгалтера.

## Языки
Польские страницы в `site/*.html` — источник. Версии на английском, украинском, русском и немецком
(`site/en/`, `site/uk/`, `site/ru/`, `site/de/`) **генерируются** — не правьте их руками:
1. Измените польскую страницу.
2. Если поменялся текст, поправьте соответствующую запись в `tools/i18n/strings.py` (ключ `pl` + 4 перевода).
3. Запустите `python3 tools/i18n/build.py` — он соберёт переводы, переключатель языков, hreflang и `sitemap.xml`.
   Если польский фрагмент из `strings.py` исчез со страницы, скрипт остановится и покажет какой.

Переводы рассчитаны на иностранцев, живущих в Польше (особенно украинцев — их там больше миллиона,
а калькуляторов польской зарплаты/налогов на украинском почти нет). Расчёты везде по польским правилам, в zł.
Тексты партнёрских офферов переводятся в `OFFERS_I18N` в `site/assets/partners.js`.

## Ниши с большим спросом и слабой конкуренцией
- **obligacje skarbowe** — после 2022 года поляки массово покупают облигации; запросы «kalkulator obligacji», «EDO czy COI» стабильно ищут каждый месяц, а сайты с калькуляторами в основном блоги.
- **nadpłata kredytu** — миллионы ипотек под плавающую ставку; хорошо монетизируется кредитными и рефинансовыми офферами.
- **IKZE** — пик запросов в ноябре–декабре (успеть внести до конца года) и в период PIT (февраль–апрель); офферы брокеров (IKE/IKZE) платят за регистрацию.

⚠️ Ставки облигаций (октябрь 2026) и лимиты IKE/IKZE (2026) прописаны в страницах — обновляйте их, когда Минфин меняет предложение (обычно в последние дни месяца) и в начале каждого года.

## Как увеличить доход
- Больше калькуляторов под частые польские запросы: kalkulator wynagrodzeń (brutto/netto),
  kalkulator kredytu hipotecznego, inflacja, emerytura, zasiłek chorobowy (L4), urlop wypoczynkowy, IKE.
- 300–800 слов полезного текста на каждой странице — для позиций в Google.
- Своя домена `.pl` (~10–50 zł/год) повышает доверие и шансы на одобрение в AdSense.

## Честно о результатах
Трафик из поиска растёт медленно: первые заметные деньги обычно через 3–12 месяцев и только
при большом количестве полезных страниц. Зато после запуска сайт работает сам.
