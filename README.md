# 💰 ФинКальк — сайт калькуляторов для пассивного дохода

Статический сайт с бесплатными финансовыми калькуляторами. Посетители приходят из поиска
(Яндекс/Google), а вы зарабатываете на рекламе и партнёрских ссылках. Хостинг бесплатный
(GitHub Pages), серверов и поддержки почти не нужно.

## Что внутри
- `site/` — готовый сайт: сложный процент, кредит, вклад, пассивный доход (правило 4%)
- `site/assets/site.js` — `SITE_CONFIG` для ID рекламы (РСЯ или AdSense)
- `.github/workflows/pages.yml` — автодеплой на GitHub Pages при пуше в `main`

## Запуск за 15 минут
1. Слейте ветку в `main`.
2. GitHub → Settings → Pages → Source: **GitHub Actions**.
3. Сайт появится по адресу `https://kavasss.github.io/asist/`.
4. Добавьте сайт в [Яндекс.Вебмастер](https://webmaster.yandex.ru) и
   [Google Search Console](https://search.google.com/search-console), отправьте `sitemap.xml`.
5. Подайте заявку в [РСЯ](https://partner.yandex.ru) или [AdSense](https://adsense.google.com).
   После одобрения впишите ID в `SITE_CONFIG` — блоки `.ad` заполнятся сами.
6. (Опционально) Купите свой домен (~200–1000 ₽/год): с ним проще пройти модерацию рекламных сетей.

## Как увеличить доход
- **Больше страниц = больше трафика.** Каждый калькулятор — отдельный поисковый запрос:
  ипотека, НДФЛ, ИИС, досрочное погашение, инфляция, пенсия, конвертер валют.
- **Партнёрки** (CPA): ссылки на вклады, брокеров, кредитные карты рядом с результатом
  расчёта — обычно платят больше, чем реклама. Не забывайте маркировку рекламы по закону.
- **Текст на страницах**: 300–800 слов полезного объяснения улучшают позиции в поиске.

## Честно о результатах
Это не «кнопка бабло». Поисковый трафик растёт медленно: первые заметные деньги обычно
через 3–12 месяцев, и только если страниц много и они полезные. Зато после запуска сайт
работает сам и почти ничего не стоит.
